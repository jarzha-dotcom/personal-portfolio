🛡️ 1. Filosofi Dasar: Local-First & Privasi Mutlak

ZhaNotes dirancang dengan prinsip dasar Local-First Software. Kami meyakini bahwa pemikiran pribadi, dokumen riset, coretan sketsa, dan catatan penting Anda adalah milik Anda seutuhnya, bukan aset korporasi atau kecerdasan buatan pihak ketiga.

Inti Kebijakan Privasi Kami:
• Tidak ada pembuatan akun wajib (tanpa login / registrasi).
• Tidak ada pelacak analitik perilaku atau piksel pemasaran.
• Tidak ada iklan pihak ketiga.
• Data utama Anda tidak dikirim ke server pusat kami.

💾 2. Di Mana & Bagaimana Data Anda Disimpan?

Secara bawaan (*default*), 100% konten yang Anda buat di ZhaNotes tersimpan di media penyimpanan internal peramban (*browser*) perangkat Anda:

IndexedDB Browser Menyimpan teks catatan, halaman kanvas, riwayat versi (*snapshots*), lampiran audio memo, serta berkas PDF beranotasi.
LocalStorage Menyimpan preferensi tampilan seperti mode tema (terang/gelap), ukuran halaman, dan bookmark pencarian cepat.

Jika Anda membersihkan cache dan riwayat browser secara total (*Clear Browsing Data*), data lokal di IndexedDB berpotensi ikut terhapus. Oleh karena itu, ZhaNotes menyediakan fitur ekspor berkas .zhn, format Word .docx, serta ZIP Backup Utuh agar Anda dapat mencadangkan dokumen Anda ke penyimpanan fisik Anda sendiri.

📤 3. Fitur "Bagikan Lewat Tautan" (Opsional)

ZhaNotes menyediakan fitur opsional untuk membagikan catatan kepada rekan kerja atau publik via tautan:

  • Enkripsi di Sisi Pengguna (Client-Side Encryption): Saat Anda membuat tautan bagikan, konten catatan dienkripsi langsung di browser Anda menggunakan Web Crypto API sebelum dikirim ke infrastruktur penyimpanan.
  • Kunci Rahasia di URL Hash: Kunci dekripsi catatan berada di bagian hash URL (setelah tanda pagar #key=...). Sesuai standar web, fragmen hash ini tidak pernah dikirimkan ke server kami. Artinya, server kami hanya menyimpan teks acak terenkripsi tanpa mampu membaca isinya.
  • Masa Berlaku: Anda dapat memilih batas waktu tautan (1 hari, 7 hari, 30 hari, atau tanpa batas). Anda juga dapat mencabut tautan sewaktu-waktu melalui dialog kelola tautan.

🎙️ 4. Izin Perangkat & Akses Hardware

ZhaNotes meminta izin browser hanya jika Anda secara aktif menggunakan fitur berikut:

  • Mikrofon (Perekam Audio Memo): Digunakan untuk merekam catatan suara dengan penanda waktu. File suara diproses langsung via MediaRecorder API dan disimpan ke IndexedDB lokal perangkat Anda. Rekaman tidak pernah diunggah ke server.
  • Akses Sistem Berkas (File System Access API): Di browser berbasis Chromium desktop, izin ini digunakan agar tombol Ctrl+S dapat menyimpan perubahan langsung ke berkas .zhn di hard drive Anda tanpa mengunduh ulang berulang kali.

🌐 5. Layanan Eksternal & Pustaka Pihak Ketiga

Untuk menjaga ukuran aplikasi tetap sangat ringan tanpa mengorbankan fungsionalitas tingkat lanjut, ZhaNotes memuat beberapa pustaka pendukung secara dinamis (*lazy load*):

  • Penyedia CDN (jsDelivr / cdnjs): Komponen rumus matematika (KaTeX) dan diagram (Mermaid) dimuat melalui CDN publik terpercaya dengan verifikasi hash integritas (SRI). Pihak CDN dapat mencatat alamat IP dan header peramban standar saat berkas diunduh pertama kali.
  • Fitur Dikte Suara (Web Speech API): Jika Anda menggunakan fitur dikte suara Bahasa Indonesia, peramban Anda (seperti Google Chrome) memproses suara melalui layanan pengenalan suara bawaan browser mereka yang tunduk pada Kebijakan Privasi masing-masing vendor peramban.
  • Kutip Wikipedia & DOI Crossref: Saat Anda memasukkan URL Wikipedia atau nomor DOI untuk sitasi otomatis, browser akan melakukan panggilan HTTP publik langsung ke API Wikipedia atau Crossref untuk mengambil metadata kutipan.

🏢 6. Privasi pada Edisi Kustom (Beli Putus)

Bagi klien korporat atau tim yang memesan Edisi Kustom ZhaNotes dengan fitur sinkronisasi awan multi-perangkat:

  • Sinkronisasi menggunakan enkripsi menyeluruh End-to-End Encryption (E2EE) AES-GCM.
  • Infrastruktur awan (Vercel KV / Cloudflare / Database) disiapkan di akun kepemilikan klien sendiri. Pihak pembuat ZhaNotes tidak memiliki akses atau pintu belakang (*backdoor*) ke database tersebut.

⚖️ 7. Hak Kendali Penuh Pengguna

Anda memegang kendali 100% atas data Anda:

  • Hak Menghapus: Anda dapat menghapus catatan kapan saja. Catatan yang dihapus masuk ke Tempat Sampah dan dapat dikosongkan permanen.
  • Hak Portabilitas: Anda bebas mengekspor seluruh catatan dalam format terbuka (.docx, .pdf, .md, .zip) tanpa terkunci sistem (*zero vendor lock-in*).
